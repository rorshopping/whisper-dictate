1. Download

Grab the latest build for your platform from GitHub Releases:

  • Windows: WhisperDictate-<version>-windows-x64.zip — unzip, run WhisperDictate.exe.
  • macOS: WhisperDictate-<version>-macos.zip — unzip, move the app to Applications.

2. First run

On first use the app downloads its speech model once (~2.4 GB per language) from Hugging Face directly to your machine. After that everything works fully offline.

3. Windows hello, macOS permissions

  • Windows: allow the app in Windows Security if prompted (unsigned developer build) and grant microphone access.
  • macOS: grant Accessibility and Input Monitoring when asked, and approve the developer certificate in System Settings → Privacy & Security.
